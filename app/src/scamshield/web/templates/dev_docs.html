API documentation

Interactive OpenAPI documentation: /docs (Swagger UI, served locally) and /openapi.json. The explorer is third-party software with known accessibility gaps (small targets, nested controls); this page and the schema file give the same information in plain form.

Authentication and limits

Send Authorization: Bearer ssk_.... Keys are scoped (lookup, report, intel, analytics) and belong to one organisation. Default limit {{ settings.api_rate_per_minute }} requests per minute per key; over the limit returns 429 with Retry-After.

Endpoints

  • GET /api/v1/indicators/lookup?value=...&type=... scope lookup
  • POST /api/v1/reports scope report
  • GET /api/v1/reports/{ref}/status scope report (your organisation's reports only)
  • GET /api/v1/threat-intel?category=... scope intel
  • GET /api/v1/org/analytics?days=30 scope analytics
curl -H "Authorization: Bearer $SS_KEY" \
  "https://staging.example/api/v1/indicators/lookup?value=%2B254700000001"

Errors: 401 invalid or revoked key, 403 missing scope, 404 not found, 422 invalid input, 429 rate limited.
