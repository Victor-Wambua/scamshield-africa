# User guide

**Everyone:** search an exact number/link/email on the home page; "Not reported does not mean safe". Use Analyse for a message (a guide, not proof). Report from `/report` (5 short steps, evidence optional). Challenge a record with "Request a correction".
**Reporters:** register to follow reports (`/mine`), add evidence when asked, withdraw, set alerts (`/notifications`), export or delete your data (`/settings`).
**Moderators:** `/mod` queue, open a report, write a reason (8+ chars), then Accept / Verify / Mark unverified / Request evidence / Attach evidence / Merge / Reject / Restrict reporter. Verify is disabled with the reason until the policy is met. `/mod/corrections` for challenges (platform admin can remove data). `/audit` verifies the hash chain.
**Institutions:** `/org` analytics, `/org/campaigns` verified threats, `/org/cases` with internal notes, `/org/exports` CSV, `/org/alerts`, `/org/reports` own reports with evidence. **Developers:** `/dev` keys (org admin), usage, docs.
**Platform admin:** `/admin` users (role change forces re-login, restrict), `/admin/orgs` approve partners and invite users, `/admin/roles`.
Staff sign in with password then an authenticator code (setup on first login; save recovery codes).
